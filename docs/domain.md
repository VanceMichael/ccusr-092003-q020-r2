# 领域资料

园区电力窗口（低电价/供电窗口）、变电节点容量、机房建设阶段、工业数据授权与可用范围、
数据驻留限制、科研合作授权、服务区域与跨境服务意向来自不同主体、不同时间点。
评审秘书处不能把某日的电价、另一日的变电余量和尚未签署的跨境意向直接拼成"建设条件"。

## 核心概念

- **证据版本（evidence revision）**：每条受控证据按版本登记，不可修改、不可覆盖；
  变化只能以新版本（新行）登记。系统只保存受控材料库引用 `source_ref` 与
  `source_sha256` 摘要，以及白名单内的规范化属性（布尔/数值/枚举/时间/受控标签）。
- **评审轮次（review round）**：每轮评审独立。轮次内对每个方案的六个维度分别
  **锁定到具体证据版本**；评估、比较、决策都只看锁定版本，不看后来的新版本。
- **六个维度**：
  - `power_window` 园区电力窗口（不出域/跨境均必需）
  - `datacenter_stage` 机房阶段（均必需，需设备就绪且交付容量不低于申请）
  - `data_scope` 工业数据授权与可用范围（均必需，需 GRANTED 且未过期）
  - `residency` 数据驻留限制（均必需；跨境方案必须为 `CROSS_BORDER_ALLOWED`）
  - `research_authorization` 科研合作授权（仅跨境方案必需）
  - `service_area` 服务区域与跨境服务意向（仅跨境方案必需）
- **容量预留（capacity reservation）**：锁定电力窗口证据时，在同一数据库事务内
  按方案申请容量预留变电节点容量。节点维护"承诺容量"；并发锁定的预留总量
  **不能越过承诺值**（`BEGIN IMMEDIATE` 串行化校验）。

## 关键规则

1. 变电节点余量被别的项目占用、承诺容量下调时，**只影响尚未锁定的方案**；
   已持有预留的方案继续有效，可用性可能显示为负，仅用于挡下新锁定。
2. 跨境条件不足（驻留仅限境内、科研授权未批、跨境意向缺失等）时，
   仍可通过比较接口只筛选 `IN_DOMAIN`（不出域）方案进行横向比较。
3. 系统在结构上不接受企业原始数据：属性按维度白名单校验，未声明字段一律拒绝；
   任何接口响应只返回受控引用、摘要与规范化属性，决策人员看不到原始台账。
4. 获批时冻结**决策快照**（六维度锁定版本、评估结论、容量口径）。获批后：
   - 该方案的证据锁定不可再修改；
   - 后续变化登记在独立的"决策后变化"中；
   - 历史页面严格区分 `original_judgement`（当时为何可行）与
     `later_changes_recorded` / `current_state_vs_snapshot`（后来变化），
     后者不回写、不修改原判断。
5. 驳回释放其容量预留，供其他尚未锁定的方案使用。

外部主体使用不含真实身份信息的引用编号。交换时间采用带偏移量的 ISO 8601 字符串
（不接受无时区时间）。运行时数据文件位置由 `DATABASE_PATH` 决定。
接口字段约定见 `contracts/entities.json`。
